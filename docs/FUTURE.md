1. 상태: 보류 (현재 구현하지 않음)

- 초기 순서·선택: 휴대폰 지역 설정이 한국(KR)이면 한국 → 일본 및 한국 선택, 일본(JP)이면 일본 → 한국 및 일본 선택. 그 외 지역은 한국 우선.
- 판별 기준: Expo expo-localization의 기기 지역 설정 사용. 휴대폰 언어, 실제 위치, 국적과는 구분.
- 사용자 선택 우선: 사용자가 국가를 직접 바꾸면 마지막 선택을 로컬에 저장하고 다음 실행 시 우선 적용(예: AsyncStorage).
- 적용 위치: 홈의 「지금 뜨는 팝업」 한국/일본 필터. 국가에 따라 필터 순서와 기본 선택을 함께 변경.
- 이번 작업: 제목·설명·필터 UI만 구현. 자동 국가 판별 및 선택 저장은 추후 작업.


2. 상태: 보류 (현재 구현하지 않음)
- 기기 언어 자동 감지
한국어로 설정된 휴대폰에서는 한국어, 일본어로 설정된 휴대폰에서는 일본어를 기본으로 표시.
- 사용자가 직접 언어 변경
마이페이지 → 설정 → 언어에서 한국어와 일본어를 선택할 수 있게 만들기.
- 선택한 언어 저장
사용자가 일본어를 선택했다면 앱을 껐다 켜도 일본어 유지.
- 실제 일본어 번역 연결
ja.json에 일본어 번역을 채우고 홈, 플레이스 등 각 화면에 적용

3. 실제 서비스 시작하면 백엔드에서 500 오류, Google 로그인 실패, DB 오류, S3 오류 같은 걸 네가 모르는 게 더 문제거든. 그래서 나중에 “운영 에러 모니터링/알림 붙이기”를 출시 체크리스트에 하나 넣자.
