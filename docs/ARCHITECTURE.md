# POPKU Architecture

## 현재 확인된 내용

- POPKU는 Flutter 기반 모바일 앱 프로젝트다.
- 모바일 앱을 우선하며, iOS를 우선 지원한다.
- Web UI는 현재 대응 범위에 포함하지 않는다.

## 확정된 계획

- 한국과 일본의 팝업스토어 목록 및 상세 화면을 제공한다.
- 국가 및 지역 필터를 제공한다.

## 미정 사항

백엔드 프레임워크, 통신 방식, 인증 구조, 데이터베이스, 파일 저장소와 인프라 구성은 아직 확정되지 않았다. 기술이 결정되고 실제 구현에 반영될 때 이 문서를 갱신한다.
