# POPKU 디자인 시스템 v0.1

POPKU는 한국과 일본의 팝업스토어를 탐색하는 모바일 앱이다. 전체 UI는 흰색을 중심으로 간결하고 충분한 여백을 두는 `White-first` 원칙을 따른다. 브랜드 초록색은 화면을 지배하는 배경색이 아니라 핵심 행동, 선택 상태, 브랜드 강조를 위한 포인트로 제한해 사용한다.

## 1. Color

| 토큰 | 값 | 사용 목적 |
| --- | --- | --- |
| `Primary` | `#22C55E` | 주요 버튼, 선택된 요소, 핵심 액션 등 브랜드 강조가 필요한 곳에 사용한다. |
| `Primary Light` | `#DCFCE7` | 선택 영역의 옅은 배경, 배지, 강조 영역 등 낮은 강도의 브랜드 표현에 사용한다. |
| `Primary Dark` | `#15803D` | 높은 대비가 필요한 브랜드 텍스트나 강조 요소에 사용한다. |
| `Info Light` | `#DBEAFE` | 운영 중인 팝업 날짜 배지의 배경에 사용한다. |
| `Info Dark` | `#1D4ED8` | 운영 중인 팝업 날짜 배지의 글자에 사용한다. |
| `Background` | `#FFFFFF` | 앱의 기본 화면 배경에 사용한다. |
| `Surface` | `#F8FAFC` | 카드, 구분 영역, 보조 컨테이너처럼 배경과 미세하게 구분되는 면에 사용한다. |
| `More Button Background` | `#F7F8FC` | 공통 더 보기 버튼의 배경에 사용한다. |
| `Text` | `#111827` | 제목과 본문을 포함한 주요 텍스트에 사용한다. |
| `Secondary Text` | `#6B7280` | 부가 설명, 메타 정보, 보조 레이블 등 우선순위가 낮은 텍스트에 사용한다. |
| `Inactive Text` | `#9CA3AF` | 선택 가능한 UI의 비선택 텍스트. 플레이스 탐색·전체 탭에 사용한다. |
| `Inactive Tab Text` | `#B8BEC8` | 기존 sheet handle, 비활성 custom 기간 선택, 안내 캐러셀 보조 숫자에 유지한다. |
| `Border` | `#E5E7EB` | 카드 윤곽선, 입력 영역 테두리, 구분선 등 요소 간 경계를 표현할 때 사용한다. |
| `Brand Gradient` | `#22C55E` → `#86EFAC` | 브랜드를 강조하는 제한된 영역에 사용하며, 방향은 왼쪽에서 오른쪽으로 적용한다. |

브랜드 초록색과 그라데이션은 화면 전체를 채우는 주 배경보다 핵심 행동과 브랜드 포인트를 드러내는 용도로 사용한다.

선택형 pill/chip은 미선택 시 `Background` 배경·`Text` 글자·`Border` 테두리, 선택 시 `Text` 배경·흰색 글자·`Text` 테두리를 사용한다. Home 국가 필터, Place 빠른/상세/지역 필터, 지도 카테고리 필터에 적용하며 status badge·정보 tag·CTA·찜·지도 marker·Community/Review 전용 palette는 유지한다. PopupGridCard 카테고리 tag만 글자 `#4B5563`, 배경 `#F3F4F6`을 사용하고 기간·MapPin·지역은 `Secondary Text`를 사용한다. PopupGridCard는 상태 badge / 제목 / 기간 / MapPin·지역·카테고리의 4줄로 표시하고 상태·기간 사이 separator는 사용하지 않는다. 위치 아이콘은 설치된 @expo/vector-icons의 Ionicons location-sharp(16px, Secondary Text)를 사용한다. 기간은 14 / 400 / 20이다.

Place 전체의 정렬 선택과 외부 기간 버튼은 표시하지 않는다. 기간은 기존 상세 필터 Sheet에서 전체·오늘·이번 주·이번 주말을 선택하며 custom은 비활성이다. 다른 상세 필터와 함께 임시 선택·적용·취소·초기화를 따르고 적용 기간은 다른 조건과 같은 행의 해제 가능한 chip으로 표시한다. 목록은 서버에서 운영 기간 겹침 조건을 적용하며 기존 기본 정렬로 10개씩 무한 스크롤한다. 상태 미선택은 종료 제외를 뜻하지만 상태 chip을 자동 선택하지 않는다. 탐색의 주간 선택과 카드 디자인은 유지하며 선택한 주의 최대 9개를 3개씩 최대 3페이지로 표시한다. 내부 페이지 전환은 지역 캐러셀과 같은 점 표시를 사용한다. 주 조회 중에는 직전 페이지 콘텐츠 높이를 유지하고, 최초 로딩은 기존 카드 3개 기준 372px를 확보한다. skeleton은 추가하지 않는다. 탐색 subtree는 전체 탭에서 display:none으로 숨기고 동일한 위치에 유지해 지역 캐러셀과 선택 주 state를 보존한다.

## 2. Typography

- 기본 글꼴: `Pretendard`
- 표기 순서: `fontSize / fontWeight / lineHeight`
- 모든 크기와 줄 높이는 Flutter 논리 픽셀 기준이다.
- 시스템 글자 크기 설정을 존중하고, 텍스트 확대 시 잘림이나 겹침이 발생하지 않도록 레이아웃을 구성한다.

| 토큰 | 규격 | 사용 목적 |
| --- | --- | --- |
| `Display` | `32 / 700 / 40` | 화면의 핵심 메시지나 가장 강조되는 대형 제목에 사용한다. |
| `Title L` | `24 / 700 / 32` | 페이지의 대표 제목에 사용한다. |
| `Title M` | `20 / 700 / 28` | 주요 섹션 제목이나 카드의 강한 제목에 사용한다. |
| `Title S` | `18 / 600 / 26` | 하위 섹션 제목이나 일반 카드 제목에 사용한다. |
| `Body` | `16 / 400 / 24` | 본문, 상세 설명 등 기본 읽기 텍스트에 사용한다. |
| `Label` | `14 / 500 / 20` | 버튼, 탭, 필터, 입력 항목명 등 짧은 조작·분류 텍스트에 사용한다. |
| `Caption` | `12 / 400 / 18` | 날짜, 위치 보조 정보, 주석 등 작은 보조 텍스트에 사용한다. |

## 3. Spacing

간격은 아래 토큰만 사용해 화면 전반의 리듬과 정렬을 일관되게 유지한다.

| 토큰 | 값 | 사용 목적 |
| --- | --- | --- |
| `Space 4` | `4` | 아이콘과 텍스트처럼 매우 밀접한 요소 사이의 최소 간격에 사용한다. |
| `Space 6` | `6` | 홈 퀵 메뉴의 아이콘 배경과 이름 사이에 사용한다. |
| `Space 8` | `8` | 연관된 작은 요소 사이의 간격에 사용한다. |
| `Space 12` | `12` | 카드 사이와 리스트 내부 요소나 작은 콘텐츠 묶음 사이에 사용한다. |
| `Space 16` | `16` | 기본 화면 좌우 여백, 카드 내부 여백, 일반 요소 사이의 표준 간격에 사용한다. |
| `Space 20` | `20` | 중간 크기 콘텐츠 묶음을 구분할 때 사용한다. |
| `Space 24` | `24` | 서로 다른 콘텐츠 그룹 사이의 간격에 사용한다. |
| `Space 32` | `32` | 기본 섹션 간격에 사용한다. |
| `Space 40` | `40` | 큰 콘텐츠 영역이나 화면 상단·하단의 넓은 여백에 사용한다. |
| `Space 56` | `56` | 홈 화면의 섹션 사이 기본 간격에 사용한다. |

기본 배치 기준은 다음과 같다.

- 일반 콘텐츠의 화면 좌우 여백: `16` (전체 너비 배너는 예외)
- 카드 내부 여백: `16`
- 카드 간격: `12`
- 섹션 간격: `32`
- 홈 화면의 섹션 사이 기본 간격: `56`
- 섹션 제목과 콘텐츠 간격: `16`
- 홈 배너와 퀵 메뉴 간격: `16`
- 홈 퀵 메뉴와 다음 섹션 간격: `56`

### 홈 퀵 메뉴

- 전체 높이 `100`, 한 줄 가로 `ScrollView`로 자유 스크롤한다. 스냅, 페이지 이동, 페이지 표시 점, 스크롤바는 사용하지 않는다.
- 첫 메뉴는 화면 왼쪽에서 `16` 떨어지고, 스크롤 영역은 오른쪽 화면 끝까지 연다. 마지막 메뉴 뒤에는 `16` 여백을 둔다.
- 메뉴 칸 간격은 `8`이다. 화면 너비에서 왼쪽 여백과 메뉴 칸 간격 다섯 개를 뺀 뒤 `5.5`로 나누어 칸 너비를 정한다. 처음에 다섯 칸과 여섯 번째 칸의 절반이 보이게 한다.
- 각 칸은 가운데 정렬한다. 아이콘 배경은 `48 × 48`, `Surface` 색상의 `Radius 12` 둥근 사각형이며 아이콘은 `24 × 24`이다.
- 메뉴 이름은 아이콘 배경 아래 `6` 간격으로 배치하며 `Caption` 크기(`12 / 400 / 18`)와 `Text` 색상을 사용한다. 이름은 한 줄로 제한한다.

### 지금 뜨는 팝업

- 퀵 메뉴 아래 `56` 간격으로 배치하고, 섹션 좌우 여백은 `16`이다.
- 제목은 `Title M`, 설명은 `Label`과 `Secondary Text` 색상을 사용하며 사이 간격은 `2`이다.
- 설명 아래 `20` 간격으로 한국·일본 필터를 둔다. 필터 높이는 `36`, 버튼 간격은 `8`, 모서리는 `Radius Full`이다.
- 선택된 필터는 `Text` 배경·테두리와 흰색 글자, 선택되지 않은 필터는 흰색 배경과 `Border` 테두리 및 `Text` 글자를 사용한다.
- 필터와 랭킹 리스트 사이 간격은 `24`이다. 국가별 1~10위를 제공하고 처음에는 1~5위만 보여 준다. 국가를 바꾸면 다시 1~5위로 접는다.
- 랭킹 카드는 왼쪽 이미지(`88 × 108`, `cover`, `Radius 8`), 오른쪽 내용, 맨 오른쪽 찜 버튼 순서다. 이미지와 내용 사이 간격은 `20`이다. 제목·날짜·태그의 시작선을 맞추고, 제목과 날짜 및 날짜와 태그 사이 간격은 각각 `8`이다. 찜 버튼은 카드 전체 높이를 기준으로 세로 중앙에 둔다.
- 순위는 이미지 내부 왼쪽 아래에 밀착한 `32 × 32` 배지에 마침표 없이 표시한다. 배지는 `Primary Dark` 배경, 흰색 `18 / 700` 숫자를 가운데 배치하고 오른쪽 위 모서리만 `Radius 8`로 둥글게 한다. 이미지의 왼쪽 아래 `Radius 8` 모서리는 유지하며 배지는 이미지 밖으로 나오지 않는다. 그림자와 테두리는 사용하지 않는다.
- 제목은 `Body` 크기에 굵기 `700`, `Text` 색상을 쓰고 최대 두 줄로 표시한다. 운영 기간은 `Caption`과 `Secondary Text` 색상, 지역·카테고리 태그는 옅은 회색 배경으로 표시한다.
- 카드는 흰색 배경에 상하 패딩 `12`를 두고 별도 둥근 외곽 테두리는 사용하지 않는다. 카드 사이 간격은 `12`, 각 카드 하단과 마지막 카드 아래에는 `Border` 색상의 `1` 구분선을 둔다. 찜 아이콘은 `22`, 독립된 터치 영역은 최소 `44 × 44`이다.
- 마지막 카드의 구분선 아래 `12` 간격으로 공통 더 보기 버튼을 둔다. 버튼은 전체 너비, 높이 `48`, `More Button Background` 배경, 테두리 없음, `Radius 12`, 가운데 정렬한 `Label` 글꼴과 `Text` 색상을 사용한다. 기본 문구는 `TOP 10 모두 보기`, 펼친 상태는 `접기`이며 화살표와 페이지 표시 점은 사용하지 않는다.

### 이번 주 새로 열려요

- 지금 뜨는 팝업 아래 홈 섹션 기본 간격 `56`으로 배치한다. 제목·설명·한국/일본 필터의 글꼴, 색상, 간격은 지금 뜨는 팝업과 같다.
- 필터 아래 `24` 간격으로 카드를 가로 자유 스크롤한다. 스냅과 페이지 표시 점은 사용하지 않는다. 화면 좌우 여백 `16`과 카드 간격 `12`를 적용하고, 첫 화면에 카드 두 개와 세 번째 카드 약 `30`이 보이도록 카드 너비를 화면 폭에 맞춰 계산한다.
- 카드 이미지는 정사각형(`1:1`), `cover`, `Radius 4`이며 카드 외곽 테두리는 사용하지 않는다. 이미지 바로 아래에 `Primary Light` 배경과 `Primary Dark` 글자의 오픈 날짜 배지를 둔다.
- 카드 내용은 이미지, 오픈 날짜 배지, 최대 두 줄 제목, 지역·장르 태그 순서다. 각 요소 사이 간격은 `8`이며 제목은 초과 시 말줄임표로 표시한다. 제목은 `Body` 크기에 굵기 `700`과 `Text` 색상을 사용하고, 태그는 `Surface` 배경의 `Caption` 글자로 표시한다. 카드별 태그 높이는 콘텐츠에 따라 달라진다.
- 한국과 일본의 카드 목록은 각 필터 선택에 따라 바뀐다. 현재 목록은 임시 데이터다.

### 플레이스 기본 레이아웃

- 화면은 Safe Area 위쪽 여백에 `24`를 더하고 좌우 여백 `16`을 유지한다. 상단 제목은 `Title L`, 오른쪽 알림 아이콘은 Lucide Bell `24`를 사용한다.
- 제목 아래 탐색·전체 탭을 왼쪽 정렬하고 탭 사이에 `20` 간격을 둔다. 헤더 하단 여백은 `12`이며 탭 상단의 별도 여백은 두지 않는다. 탭 너비는 텍스트에 맞춘다. 선택된 탭은 `16 / 700 / 24`와 `Text` 색상, 검정색 `2` 하단 인디케이터를 사용하고 비활성 탭은 `16 / 600 / 24`와 `Inactive Text` 색상을 사용한다. 탭 영역 아래에는 `Border` 색상의 `1` 구분선을 둔다. 기본 선택은 탐색이다.
- 탭 아래 `20` 간격으로 높이 `48`, `More Button Background` 배경의 검색창을 둔다. 검색 아이콘(20px)과 TextInput은 내부 row의 alignItems: center로 정렬한다. 검색 아이콘과 placeholder는 Inactive Text, 실제 입력은 Text를 사용한다. TextInput은 paddingVertical 0, includeFontPadding false, textAlignVertical center이며 별도 lineHeight나 위치 보정값을 사용하지 않는다. 안내 문구는 `팝업을 검색해보세요`다.
- 탐색 탭의 검색창 아래 `24` 간격으로 `곧 끝나요` 섹션을 둔다.
- 검색창 아래 `16` 간격으로 한 줄 가로 스크롤 빠른 필터를 둔다. 순서는 한국 / 일본 / 사전예약 / 혜택 / 상세이며 전체 칩은 두지 않는다. 칩은 텍스트 너비와 좌우 패딩 `14`로 너비를 정하고, 높이 `36`, 간격 `8`, `Label` 글꼴, `Radius Full`을 적용하며 글자를 줄바꿈하지 않는다.
- 빠른 필터는 복수 선택할 수 있다. 선택된 칩은 `Text` 배경과 테두리 및 흰색 글자, 미선택 칩은 흰색 배경과 `Border` 테두리 및 `Text` 글자를 사용한다. 미선택 시 전체를 뜻하며 한국·일본을 모두 선택해도 선택 상태를 유지하고 국가 제한을 두지 않는다. 다른 필터는 함께 선택하면 AND 조건으로 사용할 수 있도록 선택 상태를 관리한다.
- 필터 행 오른쪽에는 세로 `Border` 구분선과 고정된 원형 `ChevronDown` 버튼을 둔다. 칩 스크롤 영역 끝에는 여백을 두어 마지막 칩이 가려지지 않게 한다. 탭과 필터 선택 상태는 플레이스 화면에서 공통으로 관리한다.
- `ChevronDown`을 누르면 화면 높이의 `70%`인 상세 필터 바텀시트가 아래에서 열린다. 상단 중앙의 회색 핸들을 아래로 드래그하거나 어두운 배경을 누르면 닫힌다. 상단 제목·초기화 버튼은 없고, 내용만 세로 스크롤하며 하단 버튼은 Safe Area 위에 고정한다. Modal의 기본 slide는 사용하지 않고, absolute full-screen backdrop은 opacity만 0~1로 fade하며(기존 검정 0.4 배경 유지) 형제 Sheet만 translateY로 slide한다. 닫을 때도 fade/slide를 병렬 실행하고 완료 후 Modal을 숨긴다.
- 상세 필터는 행사 유형 / 지역 / 관심 분야 / 운영 상태 순서로 표시한다. 제목과 자동 너비 칩은 가운데 정렬하고 섹션 사이에는 여백을 둔다. 지역은 한국 다음 일본 순서이며 두 목록 사이에만 `Border` 구분선을 둔다. 국가 소제목은 없다. 한국 지역만 기본 최대 2줄까지 표시하고, 넘치는 지역은 두 번째 줄 끝의 `+N`과 아래 화살표로 펼친다. 기존 RegionFilterGroup의 실제 container/chip/+N 너비 측정으로 접힘 개수를 계산하며, 선택된 지역이 숨김 범위에 있으면 재진입 시 자동으로 펼친다. `N`은 숨겨진 실제 개수이며, 펼친 뒤에는 끝의 `접기`와 위 화살표로 돌아간다. 일본 지역은 divider 아래에 원래 순서대로 모두 표시하며 별도 접기를 제공하지 않는다. 현재 국가 선택에 따른 지역 표시 제한, 시트 높이와 하단 버튼 위치는 유지된다.
- 각 그룹은 복수 선택할 수 있고 같은 그룹의 값은 OR, 다른 그룹은 추후 AND 조건으로 사용할 수 있도록 관리한다. 지역 선택 시 해당 국가도 선택하며, 국가 해제 시 해당 국가의 지역 선택도 해제한다. 빠른 필터는 즉시 적용하고, 시트를 열면 적용 상태를 임시 상태로 복사한다. 시트 안의 선택과 하단 `초기화`는 임시 상태만 바꾸며, `팝업 보기`를 눌러야 빠른 필터에도 반영된다. 드래그·배경 터치 등으로 닫으면 임시 변경을 취소한다. 지역 필터는 현재 목업 목록에 반영하며, 다른 필터의 결과 적용은 아직 제공하지 않는다.
- 실제 적용 조건이 0개일 때만 Quick Filter를 표시하고, 하나 이상이면 동일한 한 줄을 Active Filter로 전환한다. 왼쪽에는 배경·테두리 없는 고정 초기화 action(RotateCcw 14px·strokeWidth 2.5 + 초기화, gap 4, 글자 13 / 600, Secondary Text), 초기화와 첫 chip 사이에는 #D1D5DB 가운데 점(·), 가운데에는 가로 스크롤하는 조건 chip, 오른쪽에는 기존 상세 필터 버튼을 고정한다. 조건 chip은 #F0FDF4 배경·#BBF7D0 테두리·Primary Dark 글자·Secondary Text X이며 Quick/상세/기간 조건을 모두 표시한다. X는 해당 조건만 해제하고 초기화는 국가를 포함한 모든 조건을 기본값으로 되돌린다. 마지막 조건 해제 시 Quick Filter로 복귀하며 별도 두 번째 적용 필터 행은 없다. Active 모드에서도 조건을 추가할 수 있도록 Sheet에 기존 Quick 항목을 표시하고 임시 선택·적용·취소·초기화를 따른다.

### 플레이스 탐색 지역 카드

- `오늘 새로 열어요!` 아래에 고정된 `어디로 놀러 갈까!` 제목과 2열 × 2행 지역 카드 페이지를 둔다. 좌우 여백은 `16`, 카드 간격은 가로·세로 `6`이며 카드 너비는 기존 크기를 유지한다.
- 첫 페이지는 성수·홍대·여의도·강남과 한국 설명 문구, 두 번째 페이지는 도쿄·오사카·교토·후쿠오카와 일본 설명 문구를 표시한다. 설명 문구는 제목 아래 회색 작은 글씨로 한 줄만 표시하고 넘치면 말줄임표로 처리하며 카드와 함께 좌우로 이동한다. 각 페이지는 실제 카드 영역 너비를 사용하고 페이지 사이에는 `16` 간격을 둔다. 영역 밖의 카드는 잘라내며 가로 스크롤 후 각 페이지 시작 위치에 네이티브 스냅으로 정렬한다. 카드 아래 중앙의 점 두 개로 최종 페이지를 표시하며, 선택된 점은 가로로 길다. 점을 누르면 해당 페이지로 이동하고 마지막 페이지에서 스와이프가 멈춘다.
- 카드 비율은 `1.6:1`, 모서리는 `Radius 8`이다. 이미지는 cover로 채우고 전체에 검정색 18% 오버레이를 씌운다. 지역명은 이미지 안 왼쪽 아래 `12` 여백에 흰색 `18 / 700`으로 표시한다.
- 지역 데이터와 이미지는 임시 목업이다. 카드를 누르면 전체 탭으로 이동해 해당 지역만 선택하고 그 지역의 목업 팝업을 표시한다.

### 팝업 방문 리뷰 작성

- 팝업 상세의 방문 리뷰 탭은 해당 팝업의 실제 리뷰를 표시하며, 리뷰가 없으면 `아직 방문 리뷰가 없어요` / `이 팝업에 다녀오셨나요? 첫 번째 리뷰를 남겨보세요.`와 방문 리뷰 작성 버튼을 둔다. 리뷰가 있어도 상단에 작성 버튼을 유지한다. 큰 배경 박스나 일러스트는 사용하지 않는다.
- `/reviews/write`는 기존 root Stack의 iOS 수평 전환과 Safe Area를 사용한다. 헤더는 뒤로가기·방문 리뷰 작성·등록이며 현재 팝업 이름을 확인용으로 표시한다. 팝업 선택과 커뮤니티 카테고리 선택은 없다.
- 별은 최소 44×44 터치 영역으로 정수 1~5점을 선택하며 노란색 채움으로 선택 범위를 표시한다. 별점 미선택 시 등록은 비활성이다. 후기 입력은 기존 작성 화면의 Body·높이 220·padding 16·Radius 12를 사용한다. 빈 후기는 현재 DB 계약에 따라 허용하며 사진은 기존 WebP 선택/변환/업로드 흐름으로 최대 5장이다. 실패하면 입력·별점·사진을 유지한다.

### 방문 리뷰 상세

- 본인 REVIEW 상세의 compact 메뉴는 수정·삭제를 제공하며 삭제는 destructive 확인 후 실행한다. 성공 시 항목별 제거 후 이전 화면으로 back하고, 실패 시 상세를 유지한다. `/reviews/write?editId=...`에서 기존 작성 화면을 재사용하고 제목은 방문 리뷰 수정, 저장 버튼은 수정 완료다. 팝업은 읽기 전용이며 기존 별점·본문·사진을 초기값으로 표시한다. 기존 사진 유지/제거와 새 사진 추가를 지원하고, 최종 0~5장이다. 실패 시 draft를 보존하며 createdAt 상대시간 및 기존 상세 navigation 정책은 유지한다.

- 팝업 방문 리뷰 목록과 커뮤니티 REVIEW는 별도 `/reviews/[id]` 화면을 공유한다. 기존 상세의 Safe Area·헤더·작성자·상대시간 tick·typography를 재사용하고 작성자 → 별점 → 연결 팝업 → 전체 본문 → 사진 → 좋아요·댓글 수 순서로 표시한다.
- 공용 CommunityImageCarousel을 재사용한다. 0장은 영역 없음, 1장은 indicator 없음, 2~5장은 한 페이지 한 장과 active dot/pill indicator를 사용한다. 숫자 페이지 표시는 없다.
- 카드 진입은 기존 synchronous ref lock을 사용한다. 팝업 링크는 실제 stack의 바로 이전 화면이 같은 publicId의 팝업이면 back으로 복귀한다. 그 외에는 팝업을 push해 REVIEW 상세를 history에 유지한다. 좋아요는 피드·상세·팝업 리뷰 목록 간 항목별로 동기화한다. 댓글은 공용 CommunityComments로 조회·root/답글 작성하며 댓글 수를 세 화면에 항목별 동기화한다. 본인 댓글·답글은 POST와 같은 compact 삭제 메뉴·확인을 사용한다. root thread 또는 reply를 성공 후 로컬 제거하며 답글 대상만 해제하고 입력문은 유지한다. 전체화면 뷰어는 제공하지 않는다.

### 커뮤니티 QUESTION / FREE 상세

- 피드에서 QUESTION / FREE를 누르면 root Stack의 `/community/[id]`로 이동한다. place 상세·글쓰기와 같은 iOS 수평 전환을 사용하며 FloatingTabBar 위를 불투명한 상세 화면이 덮는다.
- 헤더는 뒤로가기 / 게시글 / 더보기 아이콘이다. 본인 QUESTION/FREE 글의 더보기는 수정하기·삭제하기를 제공한다. 메뉴는 dim 위에 좌우 margin 16, Radius 24, 내부 좌우 padding 20의 compact bottom sheet로 표시한다. 핸들은 36×4이며 메뉴 row는 높이 56, outline 아이콘 22, gap 12, 글꼴 16/600이다. 두 row 사이 hairline 구분선을 두고 삭제 아이콘·글자는 destructive red다. 별도 취소 row 없이 바깥 탭 또는 핸들 아래로 끌기로 닫으며, 삭제 선택 후 기존 destructive 확인을 유지한다. 다른 사용자 글은 표시만 한다. 카드 박스 없이 카테고리 badge, 작성자, 전체 본문, 이미지, 조회수, 좋아요·댓글 수 순서로 표시한다.
- 작성자 이미지는 실제 프로필 URL을 사용하며 값이 없거나 로딩에 실패하면 기존 커뮤니티의 40×40 UserRound avatar 형태를 사용한다.
- 이미지는 정사각형 영역에 contain으로 한 장씩 표시한다. 0장이면 영역이 없고, 1장이면 indicator가 없다. 여러 장은 한 페이지 너비의 horizontal paging FlatList로 넘긴다. indicator는 비활성 6×6 dot, 활성 18×6 pill, 간격 6, 상단 간격 12이며 숫자는 표시하지 않는다. onScroll을 16ms 간격으로 받아 화면 중심에 가장 가까운 페이지로 indicator를 갱신하므로 스크롤 감속 종료를 기다리지 않는다.
- 좋아요·댓글 수 아래 구분선과 댓글 영역을 둔다. 댓글은 기존 작성자 avatar/fallback을 사용하고 별도 카드 배경·테두리 없이 본문, 상대시간, 답글 버튼을 표시한다. 답글은 항상 한 단계(24)만 들여쓴다. 답변 대상 `@닉네임`은 본문과 별도 Text로 fontWeight 700이며 본문 굵기는 기존 Body를 유지한다.
- 상세 하단에는 고정 댓글 입력창과 등록 버튼을 둔다. 답글 선택 시 `@닉네임에게 답글`과 X 취소를 표시한다. iOS KeyboardAvoidingView와 기존 Safe Area를 사용하며 댓글 시간은 상세 화면의 공통 분 단위 tick으로 갱신한다.
- 본인 글 수정은 기존 작성 화면을 공유하며 제목은 게시글 수정, 버튼은 수정 완료다. 기존 본문·이미지를 표시하고 category는 고정한다. 기존 이미지 제거와 신규 이미지 추가를 지원하며 최대 5장이다. 실패하면 입력과 미리보기를 유지한다.
- 댓글 좋아요·수정·신고, 이미지 전체화면·zoom은 구현 범위에 포함하지 않는다.

### 다국어 기반

- 앱 공통 번역 사전은 `src/locales/ko.json`, `src/locales/ja.json`에 `common`, `home`, `place`, `map`, `community`, `my` 영역으로 둔다. 화면에서는 JSON 대신 `src/locales`의 `t(key)`를 사용한다.
- 기본 언어는 한국어다. 일본어 사전의 빈 값과 없는 키는 한국어로 대체하고, 한국어에도 없는 키는 키 자체를 반환한다. 하위 항목이 있는 필터 섹션의 제목은 `_label`에 둔다. 현재 번역 함수 연결 범위는 플레이스 필터 UI이며 언어 전환은 제공하지 않는다.

### 플로팅 하단 네비게이션

- 홈, 플레이스, 지도, 커뮤니티, 마이페이지를 아이콘만 있는 캡슐형 탭바로 연결한다. 아이콘은 차례대로 Lucide `House`, `Compass`, `Map`, `MessagesSquare`, `UserRound`를 사용하고 크기는 `24`, 색상은 검정이다.
- 탭바는 화면 좌우 `20` 여백을 두고 하단 Safe Area 위에서 `12` 띄운다. 높이는 `64`, 모서리는 `Radius Full`이며 반투명 흰색 배경, 은은한 블러, 얇은 흰색 테두리와 그림자를 적용한다.
- 선택된 아이콘에는 반투명 회색의 둥근 배경을 표시한다. 메뉴 이름은 화면에 표시하지 않고 접근성 라벨로 제공한다.
- 탭바는 콘텐츠 위에 떠 있으며, 스크롤 화면의 마지막 콘텐츠가 탭바 뒤에 가리지 않도록 하단 스크롤 여백을 둔다.

## 4. Radius

| 토큰 | 값 | 사용 목적 |
| --- | --- | --- |
| `Radius 4` | `4` | 작은 태그나 미세한 모서리 처리가 필요한 요소에 사용한다. |
| `Radius 8` | `8` | 작은 버튼, 입력 영역 등 비교적 단정한 요소에 사용한다. |
| `Radius 12` | `12` | 일반 카드와 콘텐츠 컨테이너에 사용한다. |
| `Radius 16` | `16` | 강조 카드나 크기가 큰 컨테이너에 사용한다. |
| `Radius 24` | `24` | 시각적으로 부드러운 대형 영역이나 강조 요소에 사용한다. |
| `Radius Full` | `999` | 칩, 배지, 원형 버튼 등 완전히 둥근 형태에 사용한다. |


### 팝업 상세 대표 이미지

- Hero viewport는 기존 화면 너비 × 화면 너비를 유지하며 이미지 원본 비율이나 로딩 상태로 높이를 바꾸지 않는다. 상단 버튼과 Safe Area 및 sticky tab 기준은 유지한다.
- 같은 대표 이미지의 배경은 기본 RN Image의 cover, blurRadius 20, 확대 1.12배, 불투명도 0.4로 표시한다. 배경은 Hero 안에서 잘라내고 접근성에서 숨긴다.
- 앞쪽 포스터는 상단 Safe Area를 제외한 Hero 영역에서 기존 16 여백과 contain 중앙 정렬을 유지한다. 상단 위치는 insets.top + 16이며 아래·좌우 여백은 16이다. 배경은 Safe Area까지 이어지지만 실제 포스터는 들어가지 않는다. 세로·정사각·가로 이미지 전체를 표시하며 대표 이미지는 한 장이고 별도 indicator를 두지 않는다.
- URL이 없거나 앞쪽 이미지 로딩이 실패하면 기존 로컬 placeholder를 contain으로 표시한다. URL 변경 시 이미지 오류 상태를 초기화한다. Web도 동일한 RN Image 구현을 사용하고 별도 fetch나 새 라이브러리는 추가하지 않는다.

### 팝업 상세 액션

- Hero 상단은 배경 없는 흰색 ChevronLeft·Share2(24)를 사용한다. 터치 영역은 44×44, 위치는 기존 상단 Safe Area + 12 및 좌우 16이며 약한 검정 그림자(opacity 0.25, radius 2, offset 0/1)를 공유한다. 상단 찜 버튼은 두지 않는다.
- 찜 액션은 ScrollView 밖 우측 하단의 고정 pill로 표시한다. 커뮤니티 글쓰기 버튼과 같은 높이 48, Radius Full, 좌우 padding 16으로 콘텐츠에 따라 너비를 정한다. 오른쪽은 Safe Area + 16, 아래는 Safe Area + (FLOATING_TAB_BAR_BOTTOM_GAP(12) + FLOATING_TAB_BAR_HEIGHT(60)) / 2 + 16이다. 팝업 상세에는 탭바를 추가하지 않고 위치 상수의 합계 절반만 재사용한다. 기존 찜 색상 #FF5A6E, 흰색 Heart(18)와 typography.label 기반 글자(14/600/20), gap 8을 사용한다. 그림자는 커뮤니티 글쓰기 버튼과 같은 검정색, opacity 0.15, radius 12, offset 0/4, Android elevation 6이다.
- 미찜은 outline Heart·찜하기, 찜 상태는 filled Heart·찜했어요로 표시한다. 기존 찜 처리와 본문 통계 하트는 유지하며 팝업 정보·방문 리뷰 양쪽 탭에서 표시한다. 마지막 콘텐츠를 CTA 위로 스크롤할 수 있도록 하단 여백은 80이다.

### 팝업 상세 안내 캐러셀

- 공지·혜택은 제목/반응 아래에 공지 → 혜택 순서로 표시한다. 제목은 기존 상세 i18n의 공지사항/혜택 및 お知らせ/特典이며 📢/🎁는 RN 장식 요소다.
- 두 항목은 기본 RN 수평 paging을 사용하며 카드 내부 제목 행 우측에 1/2, 2/2를 표시한다(12 / 400 / 20, Inactive Tab Text). 카드 아래 indicator나 별도 여백은 없다. 실제 컨테이너 너비에서 나란히 배치한 측정 행이 최대 자연 높이를 확보하고, 두 카드 및 viewport에 같은 높이를 적용한다. 단일 항목은 자연 높이이며 숫자 pagination이 없고, 모두 비어 있으면 안내 영역을 숨긴다.
- 혜택은 소개 영역에 중복 표시하지 않는다.

### 팝업 상세 구조화 소개

- 기존 팝업 소개 영역을 유지한다. summary와 highlight 본문은 일반 본문(14 / 400 / 22)으로, 흰 배경의 소개 흐름 안에서 배열 순서대로 표시한다. highlight에는 카드 배경·모서리·내부 패딩·divider를 적용하지 않는다. summary와 첫 highlight 및 highlight 사이 간격은 24, 소제목(14 / 600 / 20)과 본문 간격은 8이다. summary 없이 highlights만 있으면 섹션 제목 아래 간격은 기존 16을 유지한다.
- highlight 제목은 KO/JA 고정 i18n 문구다. 중앙 metadata에서 SPECIAL ✨ / GOODS 🎁 / PRODUCTS 🛍️ / VIEW 👀 / EXPERIENCE 🎨 / FOOD 🍴 / SPACE 🏠 / HIGHLIGHT 📌를 관리한다. 모든 type의 이모지와 제목은 같은 줄에 간격 6으로 표시하고, 이모지는 장식으로 분리해 스크린리더에서는 제목·본문을 읽는다. unknown type은 📌와 HIGHLIGHT 제목을 사용한다. 긴 제목과 본문은 줄바꿈하며 축약하지 않는다. 혜택·공지 카드는 기존 스타일을 유지한다.
- summary/highlights/소개 이미지가 모두 없으면 소개 섹션과 해당 빈 여백·divider를 숨긴다. 공식 채널은 기존 가로 아이콘 영역을 유지하고 홈페이지의 Globe 아이콘을 추가한다.
- 제목 아래 통계 행은 항목 사이 gap 12, 아이콘·글자 사이 gap 5를 사용한다. 찜 숫자만 tabular-nums를 적용해 한 자리 숫자의 폭을 안정화하며 별도 minWidth나 고정 폭은 두지 않는다. 자릿수가 늘면 자연스럽게 확장한다. 별점은 서버 평균을 소수점 한 자리로 표시하고, 후기 0개는 `후기`, 1개 이상은 `후기 N개`로 표시하며 기존 후기 탭 이동을 유지한다.
