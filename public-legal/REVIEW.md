# 개인정보처리방침 공개 전 확인

## 반영 및 범위

운영자 결정에 따라 실제 사용하는 AWS S3·Resend·Google·Apple·OpenAI와 각 용도, 만 14세 이상 가입, 탈퇴 시 삭제·유지 구분 및 임시 인증정보 정리 기준을 유지했다. 기존에 확정된 서울 리전·S3 Versioning 비활성화·임시 업로드 2일 Lifecycle 만료도 보존했다.

담당자는 김은태, 개인정보 문의·권리 행사 이메일은 `popchive.support@gmail.com`이다. 로그인 회원의 앱 내 문의와 로그인 없이 이용하는 이메일 문의를 구분했다. 시행일은 양 언어의 상단 및 부칙 모두 **2026-10-14**로 통일했다.

RN `auth.ts`의 접근·갱신 토큰 및 기기 식별값, SecureStore 저장, 인증·요청 상태 로그와 지도 범위 로그, 기존 서버 진단 문서 및 운영자가 확정한 BE 사실에 근거해 문구를 작성했다. 확인되지 않은 보안 인증·암호화 방식·자동 삭제나 신규 업체는 추가하지 않았다. AWS 추가 조사·운영 설정 조회·배포는 하지 않았다.

## 실제 공개 전 필요한 공시 보완

아래는 아직 확정되지 않은 필수 공시 항목이다. 문구 정리와 시행일 확정만으로 최종 공개 가능하다고 판단하지 않는다.

1. **외부 서비스·국외 이전:** 실제 계약 상대·수탁자·수신자의 명칭과 연락처, 위탁·제3자 제공 관계 및 업무, 서울 이미지 저장 외 처리 국가, 이전 항목·시기·방법·목적·수신자 보유기간·법적 근거·거부 절차와 효과 및 필요한 고지·동의. 업체명과 용도 목록만으로 공시를 충족하지 않는다.
2. **보유·파기:** 이메일 문의, 유지 댓글·리뷰·이미지·신고·수정 요청·잔존 계정·동의 기록, 백업·로그, Apple 자격증명·철회 기록의 실제 최종 보유기간·종료 조건·파기 방법. 법정 보존이 적용되면 근거·항목·기간·분리 보관을 반영한다. 확인되지 않은 기간이나 삭제 완료 시각은 본문에 만들지 않았다.
3. **자동수집·권리 절차:** 실제 로그·자동수집 장치의 항목·적용 범위·거부 방법, 권리 행사 접수 후 본인·법정대리인 확인 및 처리 절차, 파기·접근 제한의 실제 운영 방법에 관한 필요한 공시를 확정한다. 인증 토큰 처리를 별도 추적 도구나 사용하지 않는 분석 서비스로 확대하지 않는다.

4. **탈퇴 후 식별 가능성:** 현재 앱과 공개 HTML의 사용자 DB 행·사용자 ID 유지 및 “완전 익명화는 아님”이라는 설명을 그대로 보존했다. 실제 운영 BE의 계정 필드 제거, 콘텐츠·로그·백업의 연결 가능성, 최종 보유·파기 동작과 대조해야 한다. 이번 작업에서는 BE 소스·운영 DB를 확인하지 않았으며, 비식별·익명화의 법적 평가를 새로 확정하지 않았다.

## 동기화와 검증

- 한국어 앱 원본은 `src/content/policies.ts`, 일본어 앱 원본은 `src/content/policies.ja.json`이다. 2026-10-14 기준 앱·한국어/일본어 Markdown의 최신 방침에 두 공개 HTML을 맞췄다. 기존 Apple 로그인·만 14세 이상 가입·탈퇴 처리와, 원문에서 보존된 보유·파기·국외이전 관련 법령 준수 문구를 반영했다.
- 각 HTML의 54개 본문 블록과 시행일이 앱 원본과 일치하고 한국어/일본어 Markdown도 앱 원본과 일치한다. HTML 본문·날짜 외 스타일·레이아웃·언어 링크·canonical은 보존했다.
- 이번 공개 HTML 동기화에서 TS·JSON·약관 원문·RN UI/API 및 `support.html`은 변경하지 않았다.
- 개인정보처리방침에 날짜 미정·빈 문단·TODO·TBD가 없음을 확인했다. 미확정 공시사항은 위 목록으로 관리한다.
- `tests/publicLegal.test.cjs`에서 공개 HTML·앱의 전체 본문/문단 순서·시행일 일치, placeholder 부재, 명시적인 HTML 태그 중첩·메타데이터·링크·기존 배포 경로를 검사한다. `tests/legalI18n.test.cjs`, `tests/signupPolicies.test.cjs`와 함께 17개 테스트가 통과했다. Hook·실제 React Compiler의 한국어→일본어→한국어/system 전환 및 가입 약관 복귀 검증도 포함한다.
- 기존 `deploy/public-legal/deploy.ps1 -Offline`의 로컬 파일·UTF-8·SHA-256 검증 및 `git diff --check`를 수행했다. `-Apply`, AWS 조회·업로드·SSM 호출, 공개 URL 접속, 실기기·브라우저 시각 검증·빌드·운영 배포는 수행하지 않았다.
- 기존 공개 URL은 `https://popchive.com/privacy`, `https://popchive.com/ja/privacy`이다. 배포 스크립트는 `public-legal/` 원본을 S3 임시 전송 경로를 통해 EC2 Nginx의 `/var/www/popchive-public/`에 전달한다. 배포 스크립트·Nginx 예시·초기 배포용 tar.gz/SHA256SUMS는 변경하지 않았다.
